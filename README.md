This extension was generated by Claude Code in five minutes on Fable 5.1 - Get your agent to install it or mirror it onto your supported browser if you deal with this shit like I do. 


## Install
1. Clone or download this repo.
2. Open `chrome://extensions`.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and pick this folder.
